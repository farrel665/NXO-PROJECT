NXO DEBLOAT 2.0.0

UI: Kotlin + Jetpack Compose + Material 3
UI XML: none (AndroidManifest.xml is still required by Android)
Backend: Shizuku non-root
Targets: Free Fire / Free Fire MAX

Implemented:
- JIT/AOT-style ART package compilation (speed-profile)
- background dexopt
- safe package-cache trim
- display supported-Hz detection
- auto max refresh request using standard Android settings
- SurfaceFlinger diagnostics
- gfxinfo FPS/frame diagnostics
- performance Game Mode request where supported
- VSync capability diagnostics, no fake disable state
- notification monitor
- FF/FF MAX session monitor while Activity is active
- Compose crosshair preview/menu
